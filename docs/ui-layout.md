# Pi Hearth 界面布局

基于 React、shadcn/ui 与 Tailwind CSS，采用左侧项目与会话、中间对话、右侧按需查看文件的桌面工作台布局。对话是主区域，右侧面板默认收起。功能与数据边界见[整体架构](architecture.md)，组件与依赖选型见[技术栈](tech-stack.md)。

## 主窗口

```text
┌──────────────────────────────────────────────────────────┐
│ pi-hearth                            面板切换  窗口控制  │
├──────────────┬───────────────────────────┬───────────────┤
│ 新建对话     │ 项目名称 / 当前会话       │ 变更 / 文件   │
│ 搜索会话     ├───────────────────────────┤               │
│              │                           │ 文件列表      │
│ ▾ pi-hearth  │ 用户消息                  │               │
│   当前会话   │                           │ 文件预览      │
│   历史会话   │ 助手回答                  │ 或代码差异    │
│              │ 工具执行记录              │               │
│ ▸ 其他项目   │                           │               │
│              ├───────────────────────────┤               │
│              │ 输入消息……                │               │
│ 打开项目     │                           │               │
│ 设置         │ 模型  上下文用量    发送  │               │
└──────────────┴───────────────────────────┴───────────────┘
```

线框展示右侧面板展开时的布局。

| 区域 | 尺寸与布局 |
| --- | --- |
| 顶栏 | 高约 40px，放置应用名称、面板切换与窗口控制 |
| 左侧导航 | 默认宽约 240px，可拖动调整和收起 |
| 中央对话 | 占据剩余空间，正文最大宽约 820px；顶部为项目与会话信息，底部固定输入区 |
| 右侧面板 | 默认宽约 400px，可拖动调整和关闭，通过“变更 / 文件”切换内容 |
| 设置 | 独立大弹窗，左侧分类、右侧表单；关闭后回到原对话位置 |

窗口变窄时优先收起右侧面板，文件通过覆盖面板打开，保证对话区可读。

## 项目与会话导航

- 左侧顶部提供无需项目的新建聊天和搜索入口。列表先显示“项目”，再显示“聊天”；普通对话位于“聊天”分组。项目操作放在分组菜单中，行内操作在悬停或键盘聚焦时显示。
- 按项目组织会话，项目可展开和收起，项目下展示当前与历史会话。
- 运行状态直接显示在对应会话行中，切换会话时后台任务继续执行。
- 添加项目、创建项目与设置入口放在左侧底部；项目菜单提供项目指令和新建会话。

## 对话与执行

用户消息使用轻背景块，助手回答保持连续正文。工具执行以紧凑的可展开记录呈现，例如“读取文件”“修改文件”“执行命令”；展开后查看参数、输出和错误。

运行过程中即可展开执行过程与思考内容，展开的思考随输出实时更新，回复结束后保留阅读状态；新一轮默认收起。需要确认的工具在执行过程收起时仍单独显示确认入口，展开后只保留一组确认操作。

需要用户确认的操作直接在对应工具记录中提供允许、拒绝按钮。任务状态与工具记录关联展示，便于定位当前执行位置和失败原因。

流式输出默认跟随最新内容。用户向上翻阅历史时停止自动滚动，底部出现“有新输出”入口。

输入区固定在对话底部，支持多行文本、模型选择和上下文用量展示。浅色主题使用淡灰底色，与白色聊天区区分；深色主题保持现有深灰底色。空闲时显示发送按钮，运行时显示停止按钮，输入中的草稿保留。

待发送队列默认在输入框上方显示一行折叠条，与选择项目的层板保持相同的内缩和连接方式。点击后展开消息明细，可逐条取消；长列表限制高度并单独滚动，切换会话时重置展开状态。

## 文件与变更

“变更”展示当前工作目录真实的 Git 差异，“文件”展示文件树与只读预览。展示范围以当前项目为准，任务级变更归属与回滚遵循架构中的后续阶段边界。

窄面板采用逐行差异。点击“展开预览”后使用更大的阅读区域，关闭预览时恢复原对话位置。

## 设置与首次使用

| 分类 | 内容 |
| --- | --- |
| 模型与凭证 | 提供商、模型、接口地址和 API Key |
| 外观 | 界面主题、窗口背景和窗口大小 |
| 运行诊断 | 运行时状态、依赖检查与日志查看 |
| 关于与更新 | 应用版本和更新信息 |

首次进入自动准备普通对话，已有使用记录时恢复上次项目和会话。添加项目关联已有文件夹，创建项目在所选父文件夹下新建目录。模型选择直接放在输入区；缺少配置时给出操作入口。

## 视觉规范

使用 shadcn/ui 官方 Base UI 版（`base-nova`）与 Neutral 主题，基础组件采用官方结构和样式。保持轻量边框、常规字重和约 4–8px 的紧凑圆角。字体使用 Windows 系统无衬线字体，侧栏正文以 13px 为主。输入框、附件、模型选择和发送按钮组成单一输入区；自动会话同步静默进行。设置使用左侧分类、右侧设置项的紧凑分栏布局。支持浅色、深色和跟随系统。

深色主题为 tabs 与当前会话使用更亮的选中底色，不显示常驻描边。悬停底色保持较弱，明确区分默认、悬停与选中状态；键盘操作保留焦点提示。

侧栏行内操作与标题共用整行底色，操作区保持透明，避免半透明背景重复叠加形成亮块；长标题用遮罩淡出，为操作按钮留出空间。会话与项目按钮共用清晰的悬停底色，选中会话与普通行保持相同强度，图标同时提亮；菜单打开时沿用悬停效果。显示操作按钮时隐藏回复状态图标，包括菜单保持打开的状态。

Windows 桌面版的窗口背景支持云母、毛玻璃和纯色，可在外观中选择，立即生效并自动保存，无需重启。云母融合桌面壁纸颜色；毛玻璃模糊透出下层窗口或桌面，并叠加跟随主题的半透明底色以保持文字清晰；纯色关闭材质效果。材质主要用于标题栏与侧栏，聊天内容区保持实色。旧配置默认使用云母，其他平台与浏览器预览禁用材质选择。
