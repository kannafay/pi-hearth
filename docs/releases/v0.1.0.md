# Pi Hearth v0.1.0

Pi Hearth 首个公开版本，为 Pi Coding Agent 提供本地优先的桌面工作台。

## 功能

- 管理本地项目、对话与 Pi 原生历史会话。
- 流式显示 Markdown 回复与思考内容，支持模型切换和停止任务。
- 展示文件与命令工具的参数、实时输出和结果，支持操作审批。
- 提供浅色、深色主题，以及 Windows 窗口背景效果设置。
- 使用简体中文安装引导，可选择安装位置。

## 下载与使用

下载 `Pi.Hearth_0.1.0_x64-setup.exe`，支持 Windows x64。安装包自带 Node.js 24.21.0 和 Pi 1.3.0，无需另外安装 Node.js、pnpm、Rust、MSVC 或全局 Pi 命令。

安装后仍需配置模型提供商与凭证，具体步骤见 [README](https://github.com/kannafay/pi-hearth#本地开发)。Git、Python 等任务工具按项目需要安装。

`SHA256SUMS` 提供安装包的 SHA-256 校验值，可使用 PowerShell 的 `Get-FileHash` 核对。

## 已知限制

- 安装包暂未做代码签名，Windows 可能显示发布者未知或信誉提示。
- 系统缺少 WebView2 时，安装过程需要联网下载该组件。
- 本次仅提供 Windows x64 安装包；OAuth、凭证命令及文档中标注的后续功能尚未接入。
